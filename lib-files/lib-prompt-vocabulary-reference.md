# lib-prompt-vocabulary-reference.md

Purpose: Prompt-language reference for steering lovable.dev toward premium local-business landing page design.

Use internally. Do not paste this whole file into final prompts.

---

## 1) High-Impact Trigger Vocabulary (Prefer)

| Category | Trigger Words |
|----------|---------------|
| Composition | editorial pacing, asymmetry, considered hierarchy, signature moment |
| Material | tactile, terracotta, ceramic, linen, matte, hand-crafted |
| Visual quality | refined, museum-quality, curated, intentional, restrained drama |
| Depth | layered, ambient depth, warm shadows, soft edge light |
| Conversion emphasis | dominant CTA, proof-first hierarchy, trust cluster |

---

## 2) Safe-Mode Vocabulary (Avoid As Primary Direction)

| Risky Word | Why It Underperforms |
|------------|----------------------|
| clean | pushes minimal-risk generic output |
| simple | strips useful visual tension |
| modern | too vague; often defaults to generic SaaS look |
| professional | shifts toward conservative corporate patterns |
| user-friendly | overweights safety over distinctiveness |

---

## 3) Replacement Swap Map

| Weak Prompt Line | Better Prompt Line |
|------------------|--------------------|
| Make it clean and modern. | Make it refined with editorial pacing and one signature moment. |
| Use a professional layout. | Use an authoritative composition with 7/5 asymmetry and clear focal hierarchy. |
| Add lots of delightful animations. | Motion budget: hero max 3 animated elements, mid-sections max 2, page max 8-10. |
| Make all sections visually interesting. | Focal budget: dominant section 60%, secondary 25%, support sections 15%. |
| Use warm colors. | Use a tactile material system with warm HSL tokens and top-left lighting. |

---

## 4) Prompt Opening Lexicon (Best First 20 Lines)

Use at least one phrase from each row:

| Slot | Recommended Phrase Pattern |
|------|----------------------------|
| Visual anchor | "[sensory scene] with physical material cues and natural light" |
| Art direction | "Explore 2-3 directions internally, commit to ONE" |
| Focal hierarchy | "Dominant 60 / Secondary 25 / Support 15" |
| Material physics | "Surfaces feel tactile; shadows warm, never pure black" |
| Motion discipline | "Motion budget capped for premium restraint" |

---

## 5) Guardrails

- Do not stack conflicting style adjectives in the same line.
- Avoid pairing "surprise me" with open-ended "be creative" without hierarchy locks.
- If a line cannot be tested visually, rewrite it to be observable.

---

## 6) High-Leverage Prompt Lines (Copy-Ready)

1. `Focal budget: Hero=60%, one secondary section=25%, all else=15% quiet support.`
2. `Art direction: explore 2 concepts internally, commit to boldest, output no alternatives.`
3. `Signature moment: [exact section/pattern] is THE stop-scrolling moment on this page.`
4. `Material system: surfaces feel like [physical material] with warm, directional light from top-left.`
5. `Mobile containment: overflow-x-hidden on main, flex-wrap on strips, max-w-full break-words on headlines.`
6. `Motion budget: hero max 3 animated elements, mid-sections max 2, page max 8-10.`
7. `Asymmetry: use 7/5 or 5/7 splits; avoid repetitive 6/6 layouts except simple trust rows.`
8. `Transitions are SIBLINGS between sections with anti-seam buffer; never nested transition bands.`
9. `Primary CTA gets glow and motion emphasis; secondary stays quiet; tertiary is text-link only.`
10. `Verification is binary: no horizontal scroll at 320px, visible hero motion, clear featured card, no transition seams.`

---

## 7) Anti-Pattern Lines (Ban)

1. `Create a modern, clean design.`
2. `Make it visually appealing.`
3. `Use appropriate colors.`
4. `Add some animations.`
5. `Ensure mobile responsiveness.`
6. `Feel free to improve as needed.`
7. `Keep it simple.`
8. `Use best practices.`
9. `Make it professional.`
10. `Adjust colors as needed.`
